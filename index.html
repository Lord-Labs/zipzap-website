A FEW THINGS WORTH KNOWING.
Before you download.
An honest beta. A few clear answers.
Talk to us on GitHub ↗


Is ZipZap completely free?+
Yes. Free and open source under the MIT license. No account, subscription, or hosted service is required.


Which systems can run it?+
The published beta supports Windows 11 x64. macOS, Linux, and mobile versions are not available.


What can I download?+
Direct HTTP and HTTPS file links. Video extraction, protected streams, torrents, and automatic browser interception are outside this published beta.


Can interrupted downloads resume?+
ZipZap saves recoverable progress and validates it before resuming. This depends on server support and the remote file remaining unchanged. Unsafe resume may require a fresh download.


Why might Windows show a warning?+
The beta is unsigned. Windows may warn before installation. Compare the installer with the published SHA-256 checksum before deciding to install. Read the release notes ↗


Does it support Arabic?+
Yes. Both the desktop app and this website support English and Arabic, including right-to-left layouts.
