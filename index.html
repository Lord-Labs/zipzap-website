05 / BEFORE YOU ASK

A few good
questions.

Ask us on GitHub↗
Is ZipZap really free?+

Yes. ZipZap is free and open source under the MIT license. No account or subscription is required.

Which operating systems are supported?+

The published beta is for Windows 11 x64. macOS, Linux, and mobile versions are not available.

Can I download videos from any website?+

ZipZap handles direct HTTP and HTTPS file links. Video extraction, protected streams, torrents, and automatic browser interception are outside the published beta.

What happens if a download is interrupted?+

ZipZap saves recoverable progress and validates it before resuming. Resume depends on server support and the file remaining unchanged. An unsafe resume may require a fresh download.

Why does Windows show a security warning?+

This first beta is unsigned, so Windows may warn before installation. Verify the installer against the published SHA-256 checksum and read the release notes before deciding to install. Release notes ↗

Does it support Arabic?+

Yes. The desktop app includes English and Arabic, with right-to-left support. This website speaks both, too — use the language switch at the top.
